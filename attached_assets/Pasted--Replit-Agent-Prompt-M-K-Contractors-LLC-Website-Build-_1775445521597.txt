# Replit Agent Prompt — M&K Contractors LLC Website Build

## PROJECT OVERVIEW

Build a complete, production-ready website for **M&K Contractors LLC** — a specialty excavation and site contracting firm in Pennsylvania. The site will be hosted on SiteGround at **mkcontractorspa.com**. Use **Next.js (App Router)** with **Tailwind CSS** and deploy-ready static export. The site must be fully responsive, SEO-optimized, and designed to generate inbound leads from general contractors and municipalities.

-----

## TECH STACK

- **Framework:** Next.js 14+ (App Router, static export via `output: 'export'`)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Fonts:** Google Fonts — `Montserrat` (headings, bold weight) + `Inter` (body, regular weight)
- **Form handling:** Client-side validation; form submissions via Formspree or a simple API route (configurable endpoint)
- **Images:** Use Next.js `<Image>` component with placeholder divs labeled with descriptive text (client will supply real photos — NO stock or AI images)
- **Schema markup:** JSON-LD structured data embedded in `<head>` of each page
- **Analytics-ready:** Include a placeholder for Google Analytics / Google Tag Manager snippet in the layout

-----

## DESIGN SYSTEM

### Color Palette

|Token          |Hex      |Usage                                           |
|---------------|---------|------------------------------------------------|
|`primary-dark` |`#1C1C1E`|Backgrounds, header, footer, dark sections      |
|`primary-light`|`#F5F5F5`|Text areas, light backgrounds                   |
|`accent`       |`#FFB800`|CTA buttons, highlights, hover states           |
|`accent-alt`   |`#FF6B00`|Secondary accent (safety orange), used sparingly|
|`secondary`    |`#3A3A3C`|Cards, secondary sections, muted text           |
|`white`        |`#FFFFFF`|Contrast, card backgrounds                      |

### Typography

- **Headings (H1–H3):** Montserrat Bold, uppercase optional for H1
- **Body / paragraphs:** Inter Regular, 16px base, 1.6 line-height
- **Buttons:** Inter Semi-Bold, uppercase, letter-spacing 0.05em

### Design Feel

“Industrial, constructiony, but clean and fresh.” Modern industrial aesthetic — strong, professional, grounded. NOT futuristic, NOT overly corporate. Think: dark backgrounds, bold yellow accents, clean whitespace, real photography.

### Layout Principles

- Full-width sections with generous vertical padding (py-16 to py-24)
- Grid-based service cards (responsive: 1 col mobile, 2 col tablet, 3 col desktop)
- Sticky header navigation
- Prominent CTA buttons on every page
- No emojis anywhere on the site

### Navigation (Sticky Header)

- **Top utility bar** (small, dark): Phone number `(267) 221-6226` | Hours: `Mon–Fri 7:00 AM – 5:00 PM` | Location: `Pennsylvania`
- **Main nav:** Logo (left) | Home | About Us | Services (dropdown) | Projects | Contact Us | **[Request a Quote]** button (right, accent color)
- **Mobile:** Hamburger menu, click-to-call phone, thumb-friendly CTA

## SEO & SCHEMA MARKUP

### Per-Page SEO

Each page must have:

- Unique `<title>` tag with primary keyword (e.g., `Public Sector Excavation Contractor in PA | M&K Contractors`)
- `<meta name="description">` — 150–160 chars with keyword + CTA language
- One H1 per page with primary keyword
- Descriptive `alt` text on all images
- Clean URL slugs as specified above

### JSON-LD Schema (embed in `<head>` of each page)

Implement the following schema types:

1. **LocalBusiness** (global, all pages):

```json
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "M&K Contractors LLC",
  "telephone": "(267) 221-6226",
  "address": {
    "@type": "PostalAddress",
    "addressRegion": "PA",
    "addressCountry": "US"
  },
  "areaServed": ["Bucks County, PA", "Montgomery County, PA", "Chester County, PA", "Delaware County, PA", "Lehigh County, PA", "Northampton County, PA", "Berks County, PA"],
  "openingHours": "Mo-Fr 07:00-17:00",
  "priceRange": "$$",
  "url": "https://mkcontractorspa.com"
}
```

1. **Service** schema on each service subpage
1. **FAQPage** schema on each service subpage (from the FAQ accordion content)
1. **AggregateRating** on Home and About pages (`ratingValue: 5, reviewCount: 3`)
1. **Review** schema on Home page (from the 3 testimonials)
1. **BreadcrumbList** on all subpages
1. **WebSite** schema (global) with `SearchAction`
